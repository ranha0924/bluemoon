# 한세인 가스안전 파일 (The Gas Safety Casebook of Han Sein)

한국가스안전공사 **가스안전 AI 게임·영상 공모전** 출품용 작품 —
실제 가스안전 수칙과 통계(공사 공식 블로그 발췌)를 그대로 추리 게임의 단서·증언·추리 문항으로
옮긴 교육용 어드벤처다. 조사관 한세인이 두 건의 가스사고 파일을 맡는다.
모든 일러스트는 **Higgsfield AI**로 제작했고, 게임은 의존성 없는 단일 HTML 파일이다.

| | 사건 | 무대 |
|---|---|---|
| CASE FILE #1 | **한여름 밤의 파열음** | 강변 캠핑장 '별무리'. 바비큐 중이던 그늘막에서 부탄캔이 터졌다 |
| CASE FILE #2 | **보이지 않는 손님** | 폭설에 갇힌 언덕 위 펜션 '설래원'. 냄새도 소리도 없이 손님들이 쓰러졌다 |

### 사건이 가르치는 것

- **사건 1 — 부탄캔** : 5대 금지(삼발이보다 큰 조리기구 · 포일 감은 석쇠 · 이단/병렬 배치 ·
  화기 근처 방치 · 직접 가열), 사용 후 연소기에서 분리, 권장사용기간 **3년**,
  보관은 **40℃ 미만**, 부풂·쉭쉭 소리는 파열 전조 — 만지지 말고 즉시 대피.
- **사건 2 — 보일러 일산화탄소** : 배기통 점검 **3종**(이탈 · 찌그러짐 · 이물질),
  CO는 **무색무취**(연료가스의 부취제와 다르다), CO경보기 교체주기 **5년**,
  보일러 점검 **연 1회 이상**, 한파에도 **2시간마다 환기**, 노랗거나 붉은 불꽃은 불완전연소 신호.

## 실행

`index.html`을 브라우저로 열면 바로 시작된다. 빌드 과정이나 서버는 필요 없다.
타이틀 → **로비(사건 선택)** → 프롤로그 → 허브 → 조사·심문 → 추리 → 진상 → 엔딩 순으로 진행된다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 게임 전체 — 화면, 엔진, 시나리오 데이터, WebAudio 효과음 |
| `assets/*.webp` | 배경 13장 + 인물 10장 = 총 23장 |

이미지는 로컬 `assets/`를 먼저 쓰고, 파일이 없으면 원본 Higgsfield CDN(PNG)으로 자동 폴백한다.
폴백 URL은 `index.html`의 `CDN` 객체에 들어 있다.
두 경로 모두 실패하면 해당 `<img>`만 숨고 게임 진행은 그대로 이어진다.

## 사건 추가하기

엔진(`G`)은 시나리오 상수를 직접 참조하지 않고 **현재 선택된 사건 객체 `G.C`만** 본다.
그래서 새 사건은 `CASE1` / `CASE2`와 같은 모양의 객체를 하나 더 만들어 `CASES`에
등록하면 끝나고, 게임 로직은 손대지 않는다.

```js
const CASE3 = {
  no:3, name:"...", cover:"<이미지 key>", intro:"로비 카드 한 줄 소개",
  hubTitle:"...", hubWord:"펜션", backLabel:"펜션으로",   // 허브 표기
  talkBg:"<이미지 key>", rain:true,                       // 심문 배경 / 바람 소리
  needTesti:"t1", needLabel:"설아의 증언",                 // 추리 해금 조건
  CLUES:{...}, TESTI:{...}, ROOMS:{...}, PEOPLE:{...},
  PROLOGUE:[...], REVEAL:[...], DEDUCE:[...],
  deduceIntro:{...}, regroup:{...},
  ending:{ img, title, text, recap:["엔딩 요약 카드에 찍힐 수칙", "..."] }
};
const CASES = { case1:CASE1, case2:CASE2, case3:CASE3 };
```

이미지를 쓰려면 `CDN` 객체에 같은 key를 추가하면 된다 (`IMG`는 `CDN`에서 자동 생성).
단서 수(`/8`), 증언 수(`/3`), 추리 문항 수는 데이터에서 세므로 사건마다 달라도 된다.
`ending.recap`은 최대 5줄 — 없으면 엔딩 요약 카드가 통째로 숨는다.

### 3D 증거 조사

방의 스팟에 `{ label, inspect:"<모델 key>", needs:"<선행 단서>" }`를 넣으면
캔버스 3D 조사 화면이 열린다. 드래그해 물체를 돌리면 뒷면이 드러난다.

| 모델 key | 물체 | 뒷면에서 확인하는 것 |
|---|---|---|
| `can` | 부탄캔 | 바닥에 새겨진 제조일 — 권장사용기간 3년 초과 |
| `alarm` | CO경보기 | 뒷면 라벨의 제조연월 — 교체주기 5년 초과 |

두께·배율·앞면 무늬·각인 문구는 `INSPECT.MODELS` 표에만 있고,
회전·투영·발견 판정 로직은 모델과 무관하게 공용이다.

### 화면 배율

`#game`은 항상 1000×625 좌표계로 그려지고, 표시 크기만 `transform:scale()`로 맞춘다
(`fitStage()`가 `--s`를 갱신). 글자·여백·토스트가 프레임과 같은 비율로 줄어들기 때문에
화면 크기별 레이아웃 분기 없이 어디서나 같은 모양을 유지한다.

### 에셋 처리 내역

원본은 Higgsfield AI로 생성한 PNG이며, 웹 배포용으로 다음과 같이 변환했다.

- **배경 13장** — 2752×1536 원본 해상도 유지, WebP q82
  - 공통: `keyart` (타이틀 키비주얼)
  - 사건 1: `cover1` `bbq` `nextsite` `firepit` `store` `end1`
  - 사건 2: `cover2` `boilerroom` `rooftop` `guestroom` `kitchen3` `end2`
- **인물 10장** — 배경 제거 후 투명 여백을 잘라내고 높이 1000px로 축소, WebP q86 (알파 유지)
  - 공통: `detective`
  - 사건 1: `boss` `parttime` `camper` `daughter`
  - 사건 2: `host` `keeper` `guest` `child` `inspector`

여백을 잘라낸 덕에 `object-fit:contain` 기준으로 인물이 화면을 꽉 채우고,
`object-position:bottom`으로 대화 상자 위에 정확히 붙는다.

## 진행 방식

1. **사건 선택** — 로비에서 사건 파일을 고른다. 사건을 시작할 때마다 단서·증언·촛불·오답이 초기화된다
2. **조사** — 방 4곳에서 단서 8개를 모은다. 일부 스팟은 선행 단서를 찾아야 열리는 3D 증거 조사다
3. **심문** — 인물 4명에게 질문한다. 일부 질문은 관련 단서나 증언을 먼저 확보해야 열린다
4. **추리** — 단서 8개 + 지정 증언을 갖추면 4문항 추리가 열린다.
   촛불 3개가 모두 꺼지면 재정비 대사 후 촛불을 되찾고 계속한다
5. **엔딩** — 진상 컷씬 뒤 **'오늘의 가스안전 수칙'** 요약 카드가 그 사건의 핵심 수칙 5줄을 정리해 준다.
   오답 횟수에 따라 **S — 가스안전 마스터 / A — 우수 조사관 / B — 진실 도달** 등급 (사건별 독립 판정).
   엔딩에서 **[다른 사건 파일]**로 로비에 돌아갈 수 있다
