# 푸른 달의 밤 (The Night of the Blue Moon)

폭풍우로 다리가 끊긴 저택 '청람장'에서 가보 사파이어 '푸른 달'이 사라졌다.
단서 8개와 증언을 모아 진상을 밝히는 한국어 추리 어드벤처 — 의존성 없는 단일 HTML 파일.

## 실행

`index.html`을 브라우저로 열면 바로 시작된다. 빌드 과정이나 서버는 필요 없다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 게임 전체 — 화면, 시나리오, 상태 관리, WebAudio 효과음 |
| `assets/*.webp` | 배경 6장, 인물 5장 |

이미지는 로컬 `assets/`를 먼저 쓰고, 파일이 없으면 원본 CDN(PNG)으로 자동 폴백한다.
폴백 URL은 `index.html`의 `CDN` 객체에 들어 있다.

### 에셋 처리 내역

원본은 Higgsfield에서 생성한 PNG(배경 1376×768, 인물 896×1200)이며,
웹 배포용으로 다음과 같이 변환했다 — 합계 18.8MB → 0.88MB.

- **배경** (`title` `study` `green` `kitchen` `parlor` `ending`) — WebP q82, 원본 해상도 유지
- **인물** (`detective` `butler` `nephew` `maid` `dealer`) — 배경이 제거된 PNG에서 투명 여백을 잘라내고 높이 1000px로 축소, WebP q86 (알파 유지)

여백을 잘라낸 덕에 `object-fit:contain` 기준으로 인물이 화면을 꽉 채우고,
`object-position:bottom`으로 대화 상자 위에 정확히 붙는다.

## 진행 방식

1. **조사** — 방 4곳에서 단서 8개를 모은다
2. **심문** — 인물 4명에게 질문한다. 일부 질문은 관련 단서를 먼저 확보해야 열린다
3. **추리** — 단서 8개 + 가정부의 목격담(`t1`)을 갖추면 4문항 추리가 열린다.
   촛불 3개가 모두 꺼지면 문항을 다시 풀 수 있다
4. **엔딩** — 오답 횟수에 따라 S / A / B 등급
