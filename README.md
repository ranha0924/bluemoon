# 한세인 사건 파일 (The Casebook of Han Sein)

탐정 한세인이 맡은 두 개의 사건을 담은 한국어 추리 어드벤처 앤솔러지 —
의존성 없는 단일 HTML 파일.

| | 사건 | 무대 |
|---|---|---|
| CASE FILE #1 | **푸른 달의 밤** | 폭풍우로 다리가 끊긴 저택 '청람장'. 가보 사파이어 '푸른 달'이 사라졌다 |
| CASE FILE #2 | **설산의 마지막 손님** | 폭설에 갇힌 산장 '갈피'. 발자국 없는 눈밭, 밀실에서 사라진 노작가 |

## 실행

`index.html`을 브라우저로 열면 바로 시작된다. 빌드 과정이나 서버는 필요 없다.
타이틀 → **로비(사건 선택)** → 프롤로그 → 허브 → 조사·심문 → 추리 → 진상 → 엔딩 순으로 진행된다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 게임 전체 — 화면, 엔진, 시나리오 데이터, WebAudio 효과음 |
| `assets/*.webp` | 사건별 배경 6장 + 인물 5장 = 총 22장 |

이미지는 로컬 `assets/`를 먼저 쓰고, 파일이 없으면 원본 CDN(PNG)으로 자동 폴백한다.
폴백 URL은 `index.html`의 `CDN` 객체에 들어 있다.
두 경로 모두 실패하면 해당 `<img>`만 숨고 게임 진행은 그대로 이어진다.

## 사건 추가하기

엔진(`G`)은 시나리오 상수를 직접 참조하지 않고 **현재 선택된 사건 객체 `G.C`만** 본다.
그래서 새 사건은 `CASE1` / `CASE2`와 같은 모양의 객체를 하나 더 만들어 `CASES`에
등록하면 끝나고, 게임 로직은 손대지 않는다.

```js
const CASE3 = {
  no:3, name:"...", cover:"<이미지 key>", intro:"로비 카드 한 줄 소개",
  hubTitle:"...", hubWord:"저택", backLabel:"저택으로",   // 허브 표기
  talkBg:"<이미지 key>", rain:true,                        // 심문 배경 / 빗소리
  needTesti:"t1", needLabel:"가정부의 목격담",              // 추리 해금 조건
  CLUES:{...}, TESTI:{...}, ROOMS:{...}, PEOPLE:{...},
  PROLOGUE:[...], REVEAL:[...], DEDUCE:[...],
  deduceIntro:{...}, regroup:{...}, ending:{img, title, text}
};
const CASES = { case1:CASE1, case2:CASE2, case3:CASE3 };
```

이미지를 쓰려면 `CDN` 객체에 같은 key를 추가하면 된다 (`IMG`는 `CDN`에서 자동 생성).
단서 수(`/8`), 증언 수(`/3`), 추리 문항 수는 데이터에서 세므로 사건마다 달라도 된다.

### 화면 배율

`#game`은 항상 1000×625 좌표계로 그려지고, 표시 크기만 `transform:scale()`로 맞춘다
(`fitStage()`가 `--s`를 갱신). 글자·여백·토스트가 프레임과 같은 비율로 줄어들기 때문에
화면 크기별 레이아웃 분기 없이 어디서나 같은 모양을 유지한다.

### 에셋 처리 내역

원본은 Higgsfield에서 생성한 PNG(배경 1376×768, 인물 896×1200)이며,
웹 배포용으로 다음과 같이 변환했다 — 합계 38.6MB → 1.8MB.

- **배경** — WebP q82, 원본 해상도 유지
  - 공통: `titleMain` (앤솔러지 타이틀 키비주얼 — 두 사건의 파일이 놓인 책상)
  - 사건 1: `title` `study` `green` `kitchen` `parlor` `ending`
  - 사건 2: `title2` `room4` `yard` `lobby` `kitchen2` `ending2`
- **인물** — 배경이 제거된 PNG에서 투명 여백을 잘라내고 높이 1000px로 축소, WebP q86 (알파 유지)
  - 공통: `detective` / 사건 1: `butler` `nephew` `maid` `dealer` / 사건 2: `owner` `broker` `hiker` `cook` `author`

여백을 잘라낸 덕에 `object-fit:contain` 기준으로 인물이 화면을 꽉 채우고,
`object-position:bottom`으로 대화 상자 위에 정확히 붙는다.

## 진행 방식

1. **사건 선택** — 로비에서 사건 파일을 고른다. 사건을 시작할 때마다 단서·증언·촛불·오답이 초기화된다
2. **조사** — 방 4곳에서 단서 8개를 모은다
3. **심문** — 인물 4명에게 질문한다. 일부 질문은 관련 단서나 증언을 먼저 확보해야 열린다
4. **추리** — 단서 8개 + 지정 증언을 갖추면 4문항 추리가 열린다.
   촛불 3개가 모두 꺼지면 재정비 대사 후 촛불을 되찾고 계속한다
5. **엔딩** — 오답 횟수에 따라 S / A / B 등급 (사건별 독립 판정).
   엔딩에서 **[📁 다른 사건 파일]**로 로비에 돌아갈 수 있다
